Viewer model OBJ ber-material dan bertekstur menggunakan Three.js / WebGL. Seret untuk orbit, scroll untuk zoom.

Memuat model…

Model sumber berisi 4.227 segitiga, 5.637 vertex, 5.637 koordinat UV, 15 material, dan texture terpisah. File OBJ telah diorientasikan Y-up, dipusatkan pada X/Z, diletakkan dengan alas Y=0, dan diskalakan ke tinggi 2 satuan dunia. Buka README.md untuk cara menjalankan serta out/lab1_vertex_trace.txt untuk angka pipeline.
