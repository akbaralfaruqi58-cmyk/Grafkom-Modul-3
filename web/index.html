Pengukuran memakai performance.now() dan gl.finish() sebelum/sesudah rangkaian render. Ini adalah waktu submit + penyelesaian GPU secara sinkron pada perangkat/browser pengujian, bukan jaminan FPS pada semua sistem.

Konfigurasi

OBJ/MTL dan seluruh PNG texture dibundel pada web/assets/. Diffuse map ditandai sebagai sRGB; material dirender dengan Lambert flat-shading untuk mendekati baseline NumPy. Mipmap dan filtering dijalankan oleh WebGL.

Untuk membandingkan frame, gunakan kamera acuan, jangan aktifkan grid atau lantai bayangan, lalu ekspor PPM. Setelah itu jalankan python compare.py out/tugu_raster_512.ppm web/mymodel_three.ppm --diff docs/evidence/lab3_difference.ppm.
